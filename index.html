Bootstrap in One Page

The components that matter, live and annotated — INFO 202

What is Bootstrap? A free CSS framework. Instead of writing your own CSS, you add ready-made class names to your HTML. One <link> tag (see the top of this file) gives you a grid, buttons, forms, and dozens of components that already look good and are mobile-responsive.

1The Grid System

Bootstrap's layout is a 12-column grid. You nest .row inside .container, then split each row into columns that add up to 12.

Three equal columns (.col):

Responsive: col-12 col-md-4 = full width on phones, thirds on desktop. Resize your browser to watch it change!

Breakpoints are the heart of responsiveness: sm ≥576px, md ≥768px, lg ≥992px, xl ≥1200px. col-md-4 means "4 columns wide once the screen is medium or bigger."

Modal (pop-up dialog)

A Bootstrap Modal
Modals need Bootstrap's JavaScript (loaded at the bottom of the page) to open and close. The data-bs-* attributes wire it up — no code needed.
Two parts to Bootstrap: the CSS (looks) and the JavaScript bundle (behavior). Static things — grid, buttons, cards — need only the CSS. Interactive things — navbar toggle, modal, accordion, dismissible alerts — need the JS <script> at the bottom of this file.
